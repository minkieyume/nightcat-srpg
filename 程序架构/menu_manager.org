#+TITLE: 程序架构 - MenuManager

* 介绍
菜单管理器架构，负责管理JRPG菜单状态的基类，继承LimboHSM。

* 关系图

}
class MenuManager{
+ transition:Dictionary
+ _return()
}

+ transition:Dictionary
+ _return()
}

MenuState o-- MenuManager : 管理
