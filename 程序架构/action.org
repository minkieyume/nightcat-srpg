#+TITLE: 程序架构 - Action

* 介绍
用来处理行动通用逻辑的类，也提供行动属性、限制等访问逻辑。

* 关系图
#+begin_src plantuml :file action_struct.png
class Character{
+ request_action(action_manager:ActionManager)
}
class Action{
+ execute()
}
class ActionManager{
+ actions:Array[ActionResource]
+ create_action(resource:ActionResource) -> Action
+ execute_action(id:StringName,gridmap:TileMaplayer)
}
class ActionResource{
+ id:StringName
+ action_logic:Script
}
class ActionServer{
- _on_action_requested(action_manager:ActionManager)
}
class GridMap{
+ tile_size
}
interface ActionLogic{
+ execute()
}

Action ..|> ActionLogic : 实现
ActionManager --|> Action : 创建
ActionManager --o ActionResource : 聚合
ActionResource --* ActionLogic : 包含
Character ..> ActionServer : 请求
ActionServer --> ActionManager : 激活
ActionServer -left-> GridMap : 引用
#+end_src
